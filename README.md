### 📱 Components for NativePHP Mobile

- **[nativephp-pull-to-refresh](https://github.com/momotombodevs/nativephp-pull-to-refresh)**: a native pull-to-refresh container for iOS and Android (NativePHP Mobile 4.5+). Your app fetches the data; the component handles scrolling and loading states.
- **[nativephp-settings](https://github.com/momotombodevs/nativephp-settings)**: small user preferences stored on the device (language, appearance, onboarding, notifications, filters).
- **[nativephp-appearance](https://github.com/momotombodevs/nativephp-appearance)**: applies the app's appearance preference without changing the system-wide theme.

### 🚀 Apps and examples

- **[Desperta](https://github.com/momotombodevs/desperta)**: a challenge-based alarm to start the day with focus. Built with Laravel and NativePHP Mobile.
- **[Elver](https://github.com/momotombodevs/elver-nativephp-app)**: forecasts, native charts, saved locations, and climate alerts. Recent weather data stays on the device.
- **[kogito-travel-agency-quarkus](https://github.com/momotombodevs/kogito-travel-agency-quarkus)**: a travel agency example built with Kogito and Quarkus (BPMN, DMN, human tasks, and SQLite).
